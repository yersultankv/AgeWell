# AgeWell 2.0 — салауатты қартаю трекері + AI көмекші (React Native, Expo)

Диплом тақырыбы: «Жасанды интеллект негізінде адамның салауатты қартаю деңгейін болжау жүйесін әзірлеу».
Қосымша диплом жүйесінің мобильдік клиенті: көрсеткіштерді жинайды, Healthy Aging Score мен биологиялық жасты есептейді,
OpenAI негізіндегі AI агентпен сөйлеседі және аккаунтты 3 факторлы қорғаумен ұстайды.

## Іске қосу

### A) Expo Snack арқылы (GitHub-тан импорт)
1. Жобаны GitHub-қа **public** репозиторий ретінде салыңыз. `App.js` пен `package.json` репоның **түбірінде** болсын.
2. https://snack.expo.dev → **Import git repository** → репо URL-ын қойыңыз.
3. **My Device** → Expo Go-мен QR-ды сканерлеңіз.
4. Snack Expo SDK 58 қолданады, телефондағы Expo Go осы нұсқаны қолдауы керек (дүкеннен соңғы нұсқасын орнатыңыз).

### B) Компьютерде
```
npm install
npx expo start
```

## Мәліметтер базасы: Supabase (PostgreSQL)
Деректер енді **нақты SQL базада** (Supabase PostgreSQL) сақталады және оны веб-панельден ашып көруге болады.

**Бір реттік баптау (тегін, ~5 минут):**
1. https://supabase.com → New project (Free). Жоба дайын болғанша күтіңіз.
2. **SQL Editor → New query** → `supabase/schema.sql` мазмұнын толық қойып, **Run** басыңыз (кестелер + RLS жасалады).
3. Дамыту кезінде: **Authentication → Providers → Email → "Confirm email" өшіріңіз** (әйтпесе тіркелгеннен кейін поштаны растау керек).
4. **Project Settings → API**: `Project URL` және `anon public` (publishable) кілтін `src/config.js` ішіне қойыңыз.
   ⚠️ `service_role` кілтін ЕШҚАШАН қоспаңыз.
5. Деректерді көру: **Table Editor** → `profiles`, `entries`, `goals`, `meds`, `chat_messages`. Қолданушылар: **Authentication → Users**.

**Кестелер:** profiles (профиль, 2FA қор. кодтары, жедел байланыс), entries (көрсеткіштер), goals, meds, chat_messages.
**Қауіпсіздік:** Row Level Security — әр қолданушы тек өз қатарларын көреді. Құпиясөз Supabase Auth ішінде хэштеледі.
**Құрылғыда қалатындар (AsyncStorage/SecureStore):** сессия, баптаулар (қараңғы режим, еске салғыш), AI кеңес кэші, OpenAI кілті, TOTP құпиясы.
**Шектеулер:** интернет қажет; TOTP құпиясы құрылғыда қалады (жаңа телефонда 8 таңбалы резервтік кодпен кіресіз); чаттағы суреттер серверге жүктелмейді.

## Асинхронды сақтау
Барлық I/O `async/await` арқылы: Supabase (`src/services/supabase.js`), AsyncStorage (`src/services/storage.js`), SecureStore (`src/services/secure.js`).
`AppContext` жүктеу кезінде `Promise.all` қолданады, жазу кезінде ref + state синхрондалады, қате болса `try/catch`.

## Құрылым
```
App.js, index.js, app.json, package.json
src/
  ai/           openai.js (REST), tools.js (function calling), agent.js (агент циклі)
  components/   қайта қолданылатын UI
  context/      AppContext (глобал күй, CRUD, auth)
  navigation/   AppNavigator
  screens/      экрандар
  services/     storage, secure, totp, biometric, notifications, scoreService, predictionApi
  theme/, utils/, hooks.js
```

## ИАЖ семинарымен байланыс
Семинардағы LSTM контекст идеясы (алдыңғы сөзді есте сақтап, «сол фильмді» → «Аватар» деп түсіну) мұнда чат жадымен жүзеге асады:
соңғы 20 хабарлама әр сұранысқа қосылады, сондықтан «оны», «сол», «бұрынғы мәнді» деген сілтемелер шешіледі.

## Диплом моделімен байланыстыру
`src/services/predictionApi.js` ішінде `API_URL` мәнін өз серверіңізге ауыстырыңыз.

## Face ID туралы
Expo Go (iOS) ішінде Face ID орнына құрылғы PIN-коды сұралады: бұл Expo Go шектеуі. Нақты Face ID үшін development build
(`eas build --profile development`) қажет, Android-та Expo Go-да да саусақ ізі/бет жұмыс істейді.

## OpenAI модельдері
Баптаулар → AI бөлімінде чат және сурет модельдерін таңдауға болады (әдепкі `gpt-5.5` және `gpt-image-2.6-flare`).
Модель атауы өзгерсе, `src/context/AppContext.js` ішіндегі `DEFAULT_SETTINGS` мәнін жаңартыңыз.

## Қорғауда айту керек
- Кілт мобильдік клиентте сақталады: оқу жобасы үшін қолайлы, нақты өнімде OpenAI сұраныстары өз серверің (proxy) арқылы өтуі керек.
- Қазіргі болжам ереже негізінде, диплом ML моделі API арқылы қосылады.
- Деректер құрылғыда сақталады (бэкенд жоқ); аккаунттар жергілікті, нақты өнімде Firebase/Supabase Auth қолданылады.
- Чаттағы суреттер сессия аяқталғанда сақталмайды (сервер көлемін үнемдеу үшін).
